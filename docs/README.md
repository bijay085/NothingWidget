# Screenshots

Put home-screen captures here so the main README can show the product.

Suggested files:

| File | Content |
| --- | --- |
| `clock.png` | Round Clock on the home screen |
| `weather.png` | Weather widget |
| `screentime.png` | Screen Time widget |
| `quick_actions.png` | Quick Actions strip |
| `device_health.png` | Device Health widget |
| `customization.png` | In-app Customize screen |

Tips:

- Capture on a Nothing Phone when possible
- Prefer dark wallpaper so the Nothing-style chrome reads clearly
- Keep width around 1080px; PNG or WebP is fine

After adding files, uncomment the image block in the root `README.md`.
